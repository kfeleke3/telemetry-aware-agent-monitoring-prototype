## Interpretation

These numbers are for interface demonstration only. The dataset contains only 10 synthetic traces, so the scores are not statistically meaningful.

The useful part of this demo is the evaluation shape:

- trace-level precision and recall,
- false positive rate,
- recall under a fixed false positive rate constraint,
- whether the monitor alerts before the toy harmful completion step,
- alert burden on benign traces.

In a future version, the same evaluation wrapper could be used with live sandbox traces and stronger monitors.
